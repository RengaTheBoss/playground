# Playground — VST3 для FL Studio

Игрушка для звука и MIDI. Минимум крутилок, максимум «поиграть».

## Что внутри

**Звук (слева)**
- **XY-пад** — тяните точку. Влево-вправо: форма волны (синус → треугольник → пила → квадрат), вверх-вниз: яркость. На паде видно текущую волну.
- **TIME** — от коротких щипков до медленных падов.
- **MOTION** — «дыхание» тембра (покачивание яркости).
- **SPACE** — реверб.
- **VOLUME** — громкость.
- **RANDOM SOUND** — случайный звук (подходит, когда не знаешь, чего хочешь).

**MIDI (справа)**
- **KEY / SCALE / OCTAVE** — тональность, лад (10 штук, включая пентатоники и блюз), октава. Любая нарисованная нота автоматически попадает в лад — фальшивых нот нет.
- **Сетка 16 × 8** — клик или протяжка мышью рисует ноты, при клике нота звучит. Подсвеченные ряды — тоника.
- **RANDOM MELODY** — случайная мелодия в выбранном ладу.
- **CHORD** — каждая нота становится аккордом (трезвучие из лада).
- **SNAP** — ноты, которые играешь с клавиатуры/MIDI-клавиш, подтягиваются к ладу.
- **LOOP** — проигрывает паттерн. Когда FL играет — синхронно с его темпом и позицией, когда FL остановлен — просто зациклено.
- **DRAG MIDI > FL STUDIO** — схватить и перетащить готовый .mid в Piano roll или Playlist. Если перетаскивание не сработает, кнопка **SAVE .MID** сохранит файл, и его можно перетащить из проводника.

Паттерн — 16 шестнадцатых (один такт 4/4). Все настройки и паттерн сохраняются вместе с проектом FL.

## Как получить .vst3 под Windows

### Вариант A — без установки чего-либо (GitHub Actions)

1. Создайте репозиторий на github.com (можно приватный) и загрузите в него всё содержимое этой папки, **включая папку `.github`**.
   Или через git:
   ```
   git init && git add . && git commit -m "Playground"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/playground.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions**: сборка стартует сама (5–10 минут). Если нет — выберите «Build Windows VST3» → **Run workflow**.
3. Когда появится зелёная галочка, откройте запуск и внизу в **Artifacts** скачайте `Playground-Windows-VST3`.
4. Распакуйте архив. Внутри: `Playground.vst3`, `Playground-Standalone.exe` (проверить звук без FL) и `install_vst3_windows.bat`.

### Вариант B — локально

Нужны: Visual Studio (2022 или новее) или Build Tools с «Разработка классических приложений на C++», CMake и Git. Запустите `build_windows.bat`.
Результат: `build\Playground_artefacts\Release\VST3\Playground.vst3`.

## Установка в FL Studio

1. Запустите `install_vst3_windows.bat` **от имени администратора** (ПКМ → «Запуск от имени администратора») или вручную скопируйте папку `Playground.vst3` в `C:\Program Files\Common Files\VST3\`.
2. В FL Studio: **Options → Manage plugins → Find installed plugins** (Start scan).
3. Добавьте инструмент: **Add → Playground** (он в списке как VST3-генератор). Повторите скан, если не видно.

## Заметки

- Движок — JUCE 8 (подтягивается автоматически при сборке). JUCE распространяется под AGPLv3/коммерческой лицензией: для личного использования это не проблема, для продажи плагина нужна лицензия JUCE.
- Исходники: `Source/Synth.h` (голос), `Source/PluginProcessor.cpp` (параметры, паттерн, экспорт MIDI), `Source/PluginEditor.cpp` (интерфейс).
- Тесты движка: `cmake -B build -DPLAYGROUND_BUILD_TESTS=ON`, цель `PlaygroundTests`.
- Те же исходники собираются под macOS и Linux (`cmake -B build && cmake --build build`).
